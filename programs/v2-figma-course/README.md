## Курс «Англійська 12–14»

Сторінка `16:314` («25 · Англійська · 12–14 · програма + урок 1»). Програма — 150 занять,
5 модулів; список занять — рамка `50:135`.

| Урок | Секція у Figma | Що є |
|---|---|---|
| 1 | `62:215` | комплект ①–⑦ + ⑦а діалог для читання + ⑧ відповіді з поясненнями; кольорове оформлення; без аудіо (рішення 20.10.2026) |
| 2 | `333:2` | комплект + ②в скрипт аудіо; **аудіо є** — [`audio/`](audio/) |
| 3 | `333:1068` | комплект + скрипт аудіо; аудіо ще немає |
| 4 | `333:2134` | комплект + скрипт аудіо; аудіо ще немає |
| 5 | `333:3200` | комплект + скрипт аудіо; аудіо ще немає |
| 6 | — | наступний: «Питання всіх типів: інтерв’ю-знайомство» |

Комплект уроку: ① картка для сайту, ② конспект педагога, ②б ключі + журнал групи,
③ пам’ятка, ④ конструктор речень, ⑤ текст для читання, ⑥ завдання до тексту,
⑦ аркуш практики A4. Хід заняття 90 хв.
