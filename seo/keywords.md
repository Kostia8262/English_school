## 2. LSI — підсилюють тематичність

Ці слова мають зустрічатися у видимому тексті, інакше Google не бачить, що
сторінка справді про дитячу англійську, а не про мовні курси взагалі:

- розмовна англійська для дітей / разговорный английский для детей
- групові заняття англійською / групповые занятия английским
- індивідуальні заняття англійською / индивидуальные занятия английским
- рівень A1 A2 B1 B2 CEFR / уровень A1 A2 B1 B2 CEFR
- Cambridge YLE Starters Movers Flyers KET PET FCE
- НМТ з англійської мови / НМТ по английскому языку
- ігровий метод вивчення мови / игровой метод изучения языка
- фоніка для дітей / фоника для детей
- носій мови / носитель языка
- пробний урок безкоштовно / пробный урок бесплатно
- заняття в Zoom / занятия в Zoom

## 6. Чого ми не робимо

- **Не дублюємо ключі в `<meta name="keywords">`** — Google ігнорує тег з 2009 року;
  він лишився на сторінці як безпечний рудимент, але розширювати його не варто.
- **Не робимо окремих адрес під `?lang=ru`** — це та сама сторінка, оголошена
  через `hreflang`. Дві адреси на одну сторінку вже коштували нам подвоєної карти сайту.
- **Не ставимо розмітку, якої немає у видимому тексті** — FAQPage без блоку
  питань на сторінці це привід для ручних санкцій, а не для сніпета.
- **Не вигадуємо координат, годин роботи й цін** — усе, що потрапляє в панель
  знань, читається користувачем як факт про бізнес.
