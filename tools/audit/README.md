# Перевірки перед пушем

```
python tools/audit/run.py
```

Повертає 1, якщо щось знайдено. Гонити перед кожним пушем — усе разом займає
секунди.

## Навіщо це взагалі

Сайт статичний, і кожна цифра на ньому продубльована в кількох файлах. Ціни,
наприклад, живуть у семи місцях одразу:

| Де | Що саме |
|---|---|
| `index.html` → `TRANS` | видимий блок «Ціни», обидві мови |
| `index.html` → `@graph` | `Offer` і `AggregateOffer` у розмітці |
| `index.html` → `<noscript>` | статичний фолбек для краулерів без JS |
| `llms.txt` | опис для AI-агентів |
| `tools/landing/content.py` | `PRICE_CALLOUT` на вікових сторінках |
| `tools/landing/pages_service.py` | таблиця на `/tsiny` |
| `tools/landing/pages_dnipro.py` | таблиця на `/dnipro` |
| `blog/skilky-koshtuye-*.html` | стаття про вартість |

Правка в одному місці без решти дає сайт, який на різних сторінках обіцяє
різні гроші. Це не про SEO — це про скаргу від батька, який побачив 1800 на
головній і 2000 у статті.

У сусідньої школи (`d:/Проекты/my_computer_new`) для цього є цілий
`tools/course-audit` на десять скриптів — там дані ще й у базі та CMS, і
розійтися можуть п'ять джерел. Нам вистачає трьох перевірок.

## Що перевіряє кожна

### `links.py`
Биті внутрішні посилання. Знає про адреси без `.html`, які віддає `.htaccess`
внутрішнім переписуванням, і пропускає Alpine-прив'язки `:href="вираз"` —
інакше половина звіту була б з неіснуючих шляхів на кшталт `/lang==='ru'`.

### `facts.py`
Звіряє цифри між усіма файлами. Ловить грошову суму або віковий діапазон, яких
немає у списку дозволених, і сторінку, де з трьох тарифів згадані рівно два —
третій майже напевно забули.

Списки `ALLOWED_MONEY` і `ALLOWED_AGES` — усередині скрипта. Змінюєте ціну —
міняйте і там, інакше перевірка почне лаятись на правильну цифру.

### `schema.py`
Розмітка Schema.org: чи розбирається JSON, чи не веде `@id` у нікуди, чи є
обов'язкові поля, чи збігається `url` у `WebPage` з `canonical` сторінки.
Це те, що Google мовчки ігнорує: сторінка просто не отримує розширений сніпет,
і зрозуміти чому без інструменту важко.

Юридичні сторінки й сторінки помилок розмітки не мають — так і має бути, вони
закриті `noindex`.

## Ще один скрипт, поруч

`shrink_svg.py` — округлює координати в декоративних SVG до цілих. Не
перевірка, а разова оптимізація: `bus.svg` має viewBox 5000×5000 при показі
на ~320 пікселів, тож дробові хвости в координатах не видно, а важать вони
третину файлу. Запускати після кожного нового експорту з ілюстратора.
