# IndexNow

Один POST, який каже пошуковим системам «ця адреса змінилася, зайдіть».
Bing, Yandex, Seznam і Naver ділять спільний пул — подавати треба один раз.

## Навіщо це саме нам

Пошук ChatGPT спирається на індекс **Bing**, а не Google. За тринадцять місяців
у нас нуль сесій із Bing і нуль переходів із ChatGPT, Perplexity та Gemini — при
тому що `robots.txt` пускає їх усіх поіменно, а текст лежить у HTML і читається
без жодного скрипта. Обхід — єдина ланка цього ланцюга, на яку статичний сайт
взагалі може вплинути.

Це **не** головний важіль. Головний — потрапити в агрегатори, які ІІ цитує в
цій ніші; без згадок ззовні модель не дізнається про школу, скільки її сайт не
обходь. Але це той важіль, який можна смикнути кодом за годину.

## Запуск

```
python tools/indexnow/submit.py --all                  # усі адреси з карти сайту
python tools/indexnow/submit.py --dry-run --all        # подивитися список, нічого не слати
python tools/indexnow/submit.py --changed origin/master..HEAD
python tools/indexnow/submit.py https://fluent-fox.site/tsiny
```

Руками зазвичай не треба: викатка сама подає сторінки, змінені в пуші
(крок «Повідомити IndexNow» у `.github/workflows/deploy.yml`, **після** rsync —
просити переобійти адресу, за якою ще лежить старий файл, означає закріпити в
індексі те, що ми щойно виправили). Крок не валить викатку: сайт уже на проді,
а непроханий обхід — річ приємна, але не обов'язкова.

## Ключ

Лежить у корені сайта файлом `<ключ>.txt`, усередині якого написаний той самий
ключ. Так вимагає протокол: сервіс качає цей файл і звіряє. **Ключ не секрет** —
його видно кожному, хто відкриє адресу, тому він і живе в цьому публічному
репозиторії.

Другої копії ключа немає ніде навмисно: єдине джерело правди — той самий файл,
який реально віддається з сайта. Скрипт знаходить його сам і перевіряє, що ім'я
збігається з вмістом; розійшлися — падає словами, а не мовчазним 403 від сервісу.

Перевипустити ключ = покласти в корінь новий файл і прибрати старий:

```
python -c "import secrets; k=secrets.token_hex(16); open(k+'.txt','w').write(k); print(k)"
```

## Що подається, а що ні

Вирішує **карта сайту**, а не наявність файла в корені. Другого списку винятків
тут немає навмисно — два списки колись розійдуться. Практичні наслідки:

- юридичні сторінки несуть `noindex`, у карті їх немає — не подаються;
- `/oplata` навмисно тримають поза картою, доки немає ключів оплати — подати її
  звідси означало б тихо скасувати те рішення;
- російські версії подаються: для індексу `?lang=ru` — окремий документ із
  власним `<title>`, canonical і `inLanguage`, а не переклад у браузері;
- адреси безрозширені (`/tsiny`, не `/tsiny.html`) — саме вони канонічні, на
  `.html` стоїть 301, і подавати редирект замість сторінки безглуздо.

Разом виходить 84 адреси: 42 записи карти × дві мови.

## Що це не лікує

Подача прискорює обхід, але не створює попиту. Якщо сторінка нікому не потрібна
або на неї нізвідки не ведуть посилання, вона й після обходу лишиться за межами
видимої видачі — саме це зараз і відбувається з широкими посадковими.
